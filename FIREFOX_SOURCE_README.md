# OTNow 1.6.1 Firefox source build

This source archive reproduces the Firefox package submitted to Mozilla Add-ons.

## Build environment

- Operating system: Windows 10 or Windows 11
- Shell: Windows PowerShell 5.1 or newer
- Required programs: none beyond the PowerShell installation included with Windows
- Node.js, npm, package managers, compilers, transpilers, minifiers, and network access are not required

## Build steps

1. Extract this source archive to a writable directory while preserving its directory structure.
2. Open Windows PowerShell.
3. Change directory to the extracted project root, which contains `manifest.firefox.json` and the `scripts` directory.
4. Run:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\scripts\package-firefox.ps1
   ```

5. The Firefox extension package is created at:

   ```text
   dist\otnow-firefox-1.6.1.zip
   ```

## What the build script does

The build script copies the readable extension source and assets into a temporary staging directory, copies `manifest.firefox.json` to the package root as `manifest.json`, disables OTNow's manual GitHub version check because Mozilla manages updates, and creates the ZIP archive. It then verifies that `manifest.json` is at the archive root.

No source files are transpiled, concatenated, minified, obfuscated, downloaded, or generated by third-party tools.
