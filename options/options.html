Exactly what is sent

A randomly generated installation ID, the OTNow version, and totals for items organized by type, reminders, moved deadlines, manual check-offs, successful refreshes, and days used.

Never sent

Names, course names or codes, assignment titles, URLs, due dates, grades, emails, student numbers, Canvas IDs, passwords, or authentication data.

You can turn sharing off at any time. OTNow then asks the server to delete that installation's aggregate row and removes the anonymous ID from this computer.

Privacy

OTNow reads only Ontario Tech Canvas pages and uses only GET requests. Coursework stays local. The optional anonymous statistics above are the only information OTNow can send to its statistics service.
