# Security policy

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue, discussion, pull request, or screenshot.

Use GitHub's private vulnerability-reporting form:

https://github.com/sil6428/OTNow/security/advisories/new

Include the affected OTNow version, a concise description, reproduction steps, and the likely impact. Remove student names, student numbers, grades, private course content, Canvas session information, and other personal data before submitting.

You should receive an acknowledgement within seven days. Please allow time to investigate and prepare a fix before publishing technical details.

## Supported versions

Security fixes are provided for the most recent published version of OTNow. Before reporting a problem, reproduce it using the latest release when it is safe to do so.

## Scope

Reports about OTNow's extension code and local data handling are in scope. Vulnerabilities in Canvas, Ontario Tech systems, Chrome, or another third-party service should be reported to that service's security team instead.
